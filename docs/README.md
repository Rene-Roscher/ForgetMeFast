# Dokumentation

| Pfad | Art | Aktualisiert wenn |
|---|---|---|
| `docs/SPEC.md` | verbindlich | der Maintainer Produkt oder Protokoll v1 ändert (nur mit ADR) |
| `docs/specs/` | verbindlich | in derselben Änderung wie der beschriebene Code |
| `docs/adr/` | verbindlich, nur anhängen | eine Entscheidung fällt oder abgelöst wird |
| `docs/PROJECT-FACTS.md` | verbindlich | sich Version, Befehl oder Freigabeliste ändert |
| `docs/product/`, `docs/business/` | verbindlich | der Maintainer die Richtung ändert |
| `docs/plans/` | Momentaufnahme nach Lieferung | nie; ein neuer Plan ersetzt den alten |

`docs/SPEC.md` ist die Quelle für Protokoll v1. Die Dateien unter `docs/specs/` verweisen darauf und
wiederholen das Protokoll nicht.
